# Furniture block library

Plan-view CAD blocks for residential and office layouts. Geometry is **1:1 millimetres**.

## Standard set

`standard/` is the bundled catalog. Click a piece in the Blocks side panel (**Standard furniture**) or INSERT the DXF path.

| Category | Pieces |
|---|---|
| Bedroom | Single / double / king bed, wardrobe |
| Living | Sofas, armchair, visitor chair, recliner, coffee / side tables, sideboard, media cabinet |
| Dining | Round 4-seat table, dining chair |
| Office | Straight desk, task chair |
| Storage | Cupboard |
| Sets | Bedroom A3 sheet (loads ~20 named blocks) |
