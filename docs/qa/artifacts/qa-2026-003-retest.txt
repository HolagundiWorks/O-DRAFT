QA-2026-003 retest — 2026-10-26

Root cause
  Shell chrome re-applied current layer / floor / units through commands that always
  called doc_mut() (Arc::make_mut), so is_dirty() became true with 0 entities.
  Session::new / Host::create alone stay clean.

Fix
  - layer.current: no-op when name already matches CLAYER
  - floor.current: no-op when name matches effective current (stored or first/default Ground)
  - drawing.units metadata: no-op when unit unchanged
  - layout.set: no-op when already on that tab without mspace
  - FillCombo / SyncDraftingUnits: skip redundant SelectedIndex/SelectedItem writes
  - Regression: cmd::layer::tests::making_the_current_layer_again_does_not_dirty_the_drawing
  - Regression: cmd::layer::tests::chrome_reselects_do_not_dirty_a_new_imperial_drawing
